# 数据库详细设计

## 数据库

SQLite。

文件：

/data/database.sqlite

## 核心表

-   admin_users
-   mailboxes
-   tags
-   mailbox_tags
-   emails
-   attachments
-   mail_generation_records
-   system_settings

## mailboxes

字段：

-   id
-   email_address
-   local_part
-   display_name
-   enabled
-   expires_at
-   created_source
-   created_at
-   updated_at

## emails

字段：

-   id
-   mailbox_id
-   sender
-   receiver
-   subject
-   body_text
-   body_html
-   verification_code
-   is_read
-   eml_path
-   received_at

## attachments

仅保存验证码相关附件。

字段：

-   id
-   email_id
-   original_name
-   stored_name
-   file_path
-   mime_type
-   file_size

## 删除策略

邮箱删除： 级联删除邮件和附件。

邮件超过10封： 删除received_at最早邮件。

同步删除： - 数据库记录 - eml文件 - 附件文件
