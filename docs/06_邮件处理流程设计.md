## 验证码提取

仅支持数字验证码。

范围：

4-8位数字。

关键词：

中文： - 验证码 - 动态码 - 安全码

英文： - verification - code - OTP - security

## 附件策略

普通附件： 丢弃。

验证码相关附件： 保存。
