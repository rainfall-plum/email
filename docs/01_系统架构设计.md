# 单域名管理员邮箱接收管理平台 - 系统架构设计

## 1. 项目定位

本系统是一个单域名、自建SMTP邮箱接收平台。

目标： - 管理员创建邮箱 - 外部邮件发送到指定邮箱 - 后台查看邮件 -
自动提取数字验证码 - 管理验证码相关附件

不提供： - 用户登录 - IMAP - POP3 - Webmail - 邮件发送

## 2. 总体架构

Internet ↓ Postfix SMTP ↓ Python Mail Worker ↓ MIME解析 ↓ 验证码识别 ↓
SQLite ↓ FastAPI ↓ Vue3后台

## 3. 技术栈

Backend: - Python 3.12 - FastAPI - SQLAlchemy - Pydantic

Frontend: - Vue3 - TypeScript - Vite - Element Plus

Database: - SQLite

Mail: - Postfix

Deployment: - Ubuntu - Nginx - HTTPS

## 4. 开发方式

开发阶段： - Python venv - Node.js - 不使用Docker

生产阶段： - Ubuntu服务器部署 - systemd管理服务
